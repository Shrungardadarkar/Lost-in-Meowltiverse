# Meowltiverse level authoring

Use this skill for any main-climb segment, portal room, boss-like cat encounter, or procedural module. Read `AGENTS.md`, `docs/PROJECT_CONTEXT.md`, `docs/BEHAVIORAL_DESIGN.md`, and `docs/ROOM_CARD_TEMPLATE.md` before designing.

Make a room card in `docs/rooms/` before code. Each room teaches one main skill or physics alteration through preview, low-risk practice, a voluntary mastery shot, and a release into a safe or comprehensible route.

Put meaningful route choices in the geometry, not in opaque chance. State portal behavior before commitment. Preserve a recoverable main route, compatible inputs and exits, a visible fall boundary, and deterministic reward conditions.

For every sensory effect, complete the cue sheet. It must communicate a gameplay fact and retain a reduced-motion alternative. Update tests and `CHANGELOG.md` with the implementation.
