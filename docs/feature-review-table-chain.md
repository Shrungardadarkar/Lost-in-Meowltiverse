# Feature review: endless pinball table chain

1. **Skill:** Read a complete playfield, control a return to either flipper, build a rescue through repeated aimed shots, then make one upper transfer shot.
2. **Choice:** The player chooses safe return lanes, a directional bank or orbit route, and whether to take an optional portal before the lit transfer scoop.
3. **Goal and feedback:** Each active table contains one visible spirit target. Its three marks, the upper scoop's locked/open color, rails, and return feeds state the current task without a prompt.
4. **Challenge match:** A table presents one primary shot grammar at a time; the next table changes its geometry or one declared physics rule only after a successful transfer.
5. **Recovery:** Missed upper shots fall back through the same table to the flippers. Side guards feed one near-miss inward; only the marked centre drain costs a bell and returns to the current table's saved feed.
6. **Compulsion boundary:** Table transfers are deterministic, score never unlocks them, and a completed biome saves a local checkpoint. There are no streaks, timers, random rewards, or pressure to continue after the false summit.
7. **Reduced motion:** The open scoop changes to a stable high-contrast ring and its linked target marks remain lit; route arrows, lane shape, and color carry the information without camera motion.
8. **Rest:** The run can pause at any return feed. A biome completes after its second table transfer and the false summit still waits for a fresh flipper tap.
