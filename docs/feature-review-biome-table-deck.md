# Feature review: authored endless biome table deck

1. **Skill:** Identify a table's one featured shot family, use a safe return to set up a committed rescue shot, then choose the lit transfer scoop.
2. **Choice:** Each table offers a clear main bank/loop, an optional portal or resonance shortcut, and a known return lane. Neither discovery route nor score is required to advance.
3. **Goal and feedback:** One possessed cat with three visible marks is the objective. Its table-local scoop stays dim until the rescue is complete; a bright open core, geometry change, and tone confirm the transfer condition.
4. **Challenge match:** Chrome Root teaches stable banks; Tide Cathedral adds one directional current; Clockwork Bloom adds one readable rhythm gate/mandala redirect. The second table in each biome remixes rather than stacks that demand.
5. **Recovery:** Every missed high shot returns through the same table toward the flippers. Lower side guides rescue one near-miss; the marked center drain costs one bell and restores the current table feed.
6. **Compulsion boundary:** Seeds select only authored layout variants with the same objective and exit. There are no escalating timers, random drops, streaks, or rewards for continuing a session.
7. **Reduced motion:** Shot direction uses chevrons and rail shape; currents use static arrows; mandalas use fixed sectors; gates use a stable aperture. Scoop state remains an unambiguous dim/open geometry.
8. **Rest:** The second table transfer saves a biome locally. Pause is available at any time, and the false summit still requires a fresh player tap to continue.
