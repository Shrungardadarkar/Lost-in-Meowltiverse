# Living machine redesign — implementation contract

Approved scope: the owner's September 28 request to build the audited missing systems. Local first; no automatic publication. This is the current design baseline; earlier module/table reviews remain historical.

1. **Skill:** cradle, release, pass, choose a shot, read its return, then combine learned shots.
2. **Choice:** wide repeatable orbit, narrower transformative ramp, optional pocket discovery. Different entrances and return flippers make the choice physical.
3. **Goal/feedback:** illuminated switches reshape connected tracks. Petal lamps, sluice position, broken seals and friendly spirits expose progress in the playfield, without messages.
4. **Challenge:** six authored chamber roles introduce one demand at a time. Seeded mirrored variants preserve roles; optional assistance changes only future entrances, never physics or rewards.
5. **Recovery:** physical side guides, sustained cradle, explicit return feeds, seven capped bells and biome checkpoints. No rail-count teleport or expiring shot credit.
6. **Compulsion guard:** no timers, score gates, random prizes, streaks or engagement optimization. Discovery rewards are deterministic and finite per pocket. False summit waits for a deliberate input.
7. **Reduced motion:** actual geometry, light states, material silhouette and directional arrows remain; remove camera vibration, decorative rotation and debris, not collision information.
8. **Closure:** pause anywhere, saved biome boundaries, voluntary false-summit continuation. A 1–2 minute segment is a playtest hypothesis, not a deadline.

## Evidence standard

Tests must separate collision/rule checks, authored route contracts, input-driven route reachability and human feel. Seed selection plus bounded local counters is **not machine learning**. Replays and generation reports support a developer-run regression → observation → authored revision loop; they must not silently rewrite levels or optimize time played.

## Scope boundary

Implement the solo prototypes of the audited mechanics, including six pocket rules, material responses, persistent rescue guides, clues, shot-chain motifs and safe transition camera. Multiplayer, clinical flow claims, production art and automatic self-training remain out of scope. Record any unverified human acceptance criteria honestly.
