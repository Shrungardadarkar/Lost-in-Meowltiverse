## Behavioral review and validation

Autonomy: optional routes, pockets, audio and assistance. Competence: same lower field, visible prerequisites and dependable returns. Relatedness: freed spirits remain helpful; clues form a finite dog trail. Rest: no pocket timer or forced summit restart. Sensory comfort: no live-play modal or strobe. Test each route mouth using actual simulated flipper input, check all return endpoints and seeded contracts, then ask a human whether the intended shot and miss are understandable. Geometry validation alone is not proof of fun or accessibility.
